# Каталог книг (Итоговый проект)

## Описание
Небольшой сервис на FastAPI для управления каталогом книг. Позволяет добавлять книги, просматривать полный список и получать информацию о конкретной книге по её идентификатору. Проект демонстрирует полный цикл разработки: от кода и тестов до CI/CD и диагностики.

## Переменные окружения
Приложение читает настройки из файла `.env` (пример в `.env.example`):
- `APP_NAME` — имя сервиса (по умолчанию: `BookCatalog`)
- `APP_VERSION` — версия приложения (по умолчанию: `1.0.0`)
- `LOG_LEVEL` — уровень логирования: `DEBUG`, `INFO`, `WARNING` (по умолчанию: `INFO`)

## Установка и запуск
1. Клонируйте репозиторий:
   git clone <ссылка_на_ваш_репозиторий>
   cd final-project-books
2. Создайте виртуальное окружение и установите зависимости:
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   pip install -r requirements-dev.txt
3. Создайте файл `.env` на основе примера:
   cp .env.example .env
4. Запустите приложение (без --reload для штатного режима работы):
   uvicorn app_final:app --host 0.0.0.0 --port 8000
5. Откройте интерактивную документацию в браузере: http://localhost:8000/docs

## Запуск тестов
Проект включает автоматические тесты (pytest), которые проверяют:
- Работоспособность диагностических маршрутов (`/health`, `/version`)
- Корректность добавления книг и структуру ответа API
- Валидацию данных (отклонение запросов без обязательных полей)
- Обработку ошибок (например, поиск несуществующей книги по ID)

Локальный запуск всех тестов:
```bash
python3 -m pytest -v
```

## Диагностика и логи
- Проверка работоспособности: GET /health (должен вернуть {"status": "ok"})
- Версия приложения: GET /version
- Логи: основные события (запуск, добавление книги, ошибки поиска) выводятся в стандартный поток stdout. Уровень детализации настраивается через переменную LOG_LEVEL.
