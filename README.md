# 📚 Каталог книг (Итоговый проект)

Сервис на FastAPI для управления каталогом книг. Приложение позволяет добавлять книги в базу, получать полный список и находить конкретную книгу по её уникальному идентификатору. Предназначен как учебный пример микросервиса с полным циклом разработки, тестирования и CI/CD.

---

## ⚡ Быстрый старт

### 1. 📥 Клонирование и окружение
Склонируйте репозиторий и создайте виртуальное окружение:
```bash
git clone https://github.com/NatSergeevich/final-project-books.git
cd final-project-books
python3 -m venv venv
```

Активируйте окружение:
- **Linux/macOS:** `source venv/bin/activate`
- **Windows:** `venv\Scripts\activate`

### 2. 📦 Установка зависимостей
```bash
python3 -m pip install --upgrade pip
python3 -m pip install -r requirements.txt
python3 -m pip install -r requirements-dev.txt
```

### 3. ⚙️ Переменные окружения
Приложение использует настройки из переменных окружения. Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

Доступные переменные:
- `APP_NAME` — название сервиса (по умолчанию: "BookCatalog")
- `APP_VERSION` — версия приложения (по умолчанию: "1.0.0")
- `LOG_LEVEL` — уровень логирования: INFO, DEBUG, WARNING (по умолчанию: "INFO")

---

## 🚀 Запуск приложения

Запустите сервер:
```bash
python3 -m uvicorn app_final:app --host 0.0.0.0 --port 8000
```

После запуска:
- 🌐 Основное приложение доступно по адресу: http://127.0.0.1:8000
- 📖 Интерактивная документация (Swagger): http://127.0.0.1:8000/docs

---

## 🧪 Запуск тестов

Для запуска автоматических тестов выполните:
```bash
python3 -m pytest -v
```

**Что проверяют тесты (всего 5):**
- ✅ Работоспособность маршрутов `/health` и `/version`
- ✅ Корректное добавление книги и структура ответа API
- ✅ Валидация данных (код 422 при отсутствии обязательных полей)
- ✅ Поиск книги по параметру `book_id`
- ✅ Обработка ошибки 404 при поиске несуществующей книги

## 🔍 Диагностика и примеры запросов

### Проверка работоспособности
```bash
curl http://127.0.0.1:8000/health
# Ожидаемый ответ: {"status": "ok", "service": "BookCatalog"}
```

### Проверка версии
```bash
curl http://127.0.0.1:8000/version
# Ожидаемый ответ: {"version": "1.0.0"}
```

### Добавление книги (POST запрос)
```bash
curl -X POST http://127.0.0.1:8000/books \
  -H "Content-Type: application/json" \
  -d '{"title": "1984", "author": "George Orwell", "year": 1949}'
```

### Получение книги по ID (GET запрос)
*(Замените `<book_id>` на реальный ID из ответа предыдущего запроса)*
```bash
curl http://127.0.0.1:8000/books/<book_id>
```

## 📂 Структура проекта

- `app_final.py` — основной код приложения FastAPI (маршруты, логирование, валидация)
- `test_app.py` — набор автоматических тестов (pytest)
- `requirements.txt` / `requirements-dev.txt` — зависимости для запуска и разработки
- `.github/workflows/ci.yml` — конфигурация GitHub Actions для автоматического тестирования и сборки артефакта
- `.env.example` — безопасный шаблон переменных окружения
- `.gitignore` — исключения для Git (чтобы не публиковать секреты)

## 🤖 CI/CD (GitHub Actions)

Workflow запускается автоматически на каждый `push` и `pull request`:
1. Устанавливает зависимости
2. Запускает `pytest -v`
3. Если тесты прошли успешно — сохраняет `artifact` с файлами приложения

**Где найти артефакт:**  
Вкладка **Actions** → нужный зелёный запуск → блок **Artifacts** внизу страницы

## 💡 Если что-то не работает

### ❌ ModuleNotFoundError: No module named 'fastapi'
**Причина:** Не активировано виртуальное окружение или не установлены зависимости.  
**Решение:**
```bash
source venv/bin/activate
pip install -r requirements.txt
```

### ❌ Address already in use
**Причина:** Порт 8000 уже занят другой программой.  
**Решение:** Запустите на другом порту:
```bash
python3 -m uvicorn app_final:app --host 0.0.0.0 --port 8001
```

### ❌ Ответ 422 (Unprocessable Entity)
**Причина:** В JSON-запросе неправильные данные.  
**Примеры ошибок:**
- Отсутствует обязательное поле (`author` или `year`)
- `year` не является числом  
**Решение:** Проверьте формат запроса. Детали ошибки будут в поле `detail` ответа.

### ❌ Ответ 404 на /books/{id}
**Причина:** Книги с таким ID нет в памяти.  
**Важно:** Данные хранятся только до перезапуска сервера (в памяти приложения).
